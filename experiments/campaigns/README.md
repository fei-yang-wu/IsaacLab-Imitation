# Experiment campaigns

Campaign directories provide chronological navigation without making dates the
owner of reusable code.

Name a campaign `YYYY-MM-DD-short-purpose`, using the date when its protocol
was frozen or first submitted. A campaign README is the authoritative index
for that run family. Canonical implementations remain in topical directories,
and optional `run.sh` or `submit.sh` files here are thin wrappers.

The repository-wide current pointer and lifecycle policy live in
[`experiments/README.md`](../README.md). Do not infer that the lexicographically
latest campaign is automatically active.
